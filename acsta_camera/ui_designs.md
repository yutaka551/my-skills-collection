# 画面設計（UI Designs）

本ドキュメントは「アクスタカメラ」アプリの画面設計・UI仕様をまとめたものです。

## 1. スプラッシュ画面
- アプリ名・ロゴのみ表示
- メッセージ等は表示しない

## 2. カメラプレビュー画面
- リアルタイムカメラ映像を全画面表示
- 撮影ボタン（充電コネクタがある側の端中央に配置。縦画面なら下中央、横画面なら右中央。2点フォーカス指定までは非活性。端末の向きで右利き・左利き両対応）
- フォーカスガイド：
  - 画面タップでフォーカスポイントを2点指定
  - タップ位置にマーカー表示
  - 1点目・2点目を順に指定。再タップで1点目に戻る
  - 2点指定するまで撮影ボタンは非活性
  - 前回指定した2点は記憶
- 設定ボタン（画面右上・歯車アイコン）
- 小プレビュー（撮影後、左下に長方形で5秒表示、アニメなし、タップで写真アプリで画像を開く。共有は写真アプリ側で実施）
- ホワイトバランス・明るさ（露出）は1点目指定時に自動設定。必要な場合のみユーザーがスライダーUIで手動調整でき、調整した場合のみその値を適用。
  - スライダーUIはカメラプレビュー画面上にオーバーレイ表示
  - 「リセット」ボタン（自動値に戻す）、閉じるボタン付き

## 3. 設定画面
- 保存先（内部ストレージ/SDカード等）
- 画質（解像度選択）
- グリッド表示ON/OFF
- フラッシュはOFF固定
- UIテーマはOS設定に従う

## 4. その他仕様
- 合成写真は自動保存
- focus-stackライブラリで深度合成
- 共有機能はアプリ本体には搭載せず、写真アプリ側で実施
- 削除機能は無し（写真管理は外部アプリに委任）
