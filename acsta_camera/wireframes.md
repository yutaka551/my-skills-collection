# ワイヤーフレーム（アクスタカメラ）

---

## 1. スプラッシュ画面

```
+-----------------------------+
|                             |
|         [ロゴ画像]          |
|       アクスタカメラ        |
|                             |
+-----------------------------+
```
- アプリ名とロゴのみ中央表示

---

## 2. カメラプレビュー画面

### （A）縦画面（ポートレート）
```
+-----------------------------+
| [歯車]                     |
|                             |
|   (カメラプレビュー映像)    |
|                             |
|                             |
| [小プレビュー]    [● 撮影]  |
+-----------------------------+
```
- 右上：設定（歯車アイコン）
- 充電コネクタがある側（通常は下）の端中央：撮影ボタン（2点フォーカス指定までは非活性、端末の向きで右利き・左利き両対応）
- 左下：小プレビュー（撮影後5秒表示、タップで写真アプリ起動）

### （B）横画面（ランドスケープ）
```
+---------------------------------------+
| [歯車]                      [         |
|                                       |
|    (カメラプレビュー映像)      [● 撮影] |
|                                       |
| [小プレビュー]                         |
+---------------------------------------+
```
- 左上：設定（歯車アイコン）
- 充電コネクタがある側の端中央：撮影ボタン（2点フォーカス指定までは非活性、端末の向きで右利き・左利き両対応）
- 左下：小プレビュー（撮影後5秒表示、タップで写真アプリ起動）

- 画面タップでフォーカスポイント指定（マーカー表示、2点まで。再タップで1点目に戻る）
- 必要時のみ、画面上にホワイトバランス・露出調整用スライダーUIがオーバーレイ表示

### ホワイトバランス・露出調整UI（オーバーレイ例）
```
+-----------------------------+
|                             |
|   (カメラプレビュー映像)    |
|                             |
|  WB: [====|-----]           |
|  露出: [--|=======]         |
| [リセット]   [閉じる]       |
+-----------------------------+
```
- スライダーUIは必要時のみ表示
- 「リセット」「閉じる」ボタン付き

---

## 3. 設定画面

```
+-----------------------------+
|        設定                 |
|-----------------------------|
| 保存先： [内部/SD]          |
| 画質：   [高/中/低]         |
| グリッド表示： [ON/OFF]     |
|                             |
|        [戻る]               |
+-----------------------------+
```
- 保存先、画質、グリッド表示の各種設定
- 戻るボタンでカメラプレビュー画面に戻る
